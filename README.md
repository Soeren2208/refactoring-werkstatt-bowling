# Refactoring-Werkstatt: Bowling

Vorlage für das Arbeitsblatt „05 Refactoring-Werkstatt“.

Die Klasse `Bowling` rechnet richtig, ist aber schwer zu lesen. Eure Aufgabe ist es, den Code verständlich zu machen, ohne sein Verhalten zu ändern.

## Loslegen

1. In IntelliJ: **File → New → Project from Version Control**, die Adresse dieses Repositorys eintragen und **Clone** wählen.
2. Warten, bis IntelliJ das Maven-Projekt geladen hat.
3. Rechtsklick auf den Ordner `src/test/java` → **Run 'All Tests'**.

Alle Tests müssen grün sein, bevor ihr anfangt: `BowlingTest` mit 5 Tests und `BowlingAcceptanceTest` mit 12 Tests.
